Tech Arena 2026 entry. The entry was a team project; this repository does not
claim sole authorship of all historical experiments. Code and writing were
developed with AI assistance. The public implementation was checked against
archived inference code and numerical records.

The portable V142 calculation follows `experiments/v142/replay.py` from the
recovered research archive. Its source SHA-256 is
`b099e9b360203100a8a93f8b3d30737d59f0602da7876b1a46045ce9782021d6`.

features and an explicit weekend flag, validates shapes and bounds, and handles
zero support. The synthetic parity record documents comparison with the
historical function. The full archived script and its private inputs are not
redistributed.
